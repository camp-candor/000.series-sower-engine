The **Monorepo Boundary Gate & Budget Profiler** serves as the initial zero-cost ($T_0 = \$0.00$) legislative and mechanical firewall across the monorepo. Its mandate is to structurally enforce the physical separation between pure mathematical evaluation (the Simulation Kernel) and downstream execution runtimes (rendering nodes, media encoders, OS-level sub-processes, and cloud APIs).

#### Monorepo Invariants

1. **The Zero-Runtime Law:** The monorepo root `package.json` must contain zero application-level dependencies (e.g., `react`, `@octokit/rest`, `axios`, `remotion`, `hono`). Root `devDependencies` are strictly confined to build tooling: `typescript`, `eslint`, `prettier`, `dependency-cruiser`, and `@cloudflare/vitest-pool-workers`.
2. **Absolute Structural Monorepo Parity:** Domain units maintain strict 1:1 structural parity across packages under `packages/<domain>/`. Units are self-contained and forbidden from collapsing into shared, unverified helper dumps.
3. **The Unidirectional Dependency Flow:** Upstream packages never import downstream packages. `packages/300.engine` and `packages/001.lore` are strictly forbidden from referencing `apps/worker`, `apps/astro`, `@cloudflare/*`, or native Node.js process APIs (`child_process`, `fs`, `net`).

#### 2. The Budget Profiler Matcher (`test/budget-matcher.setup.ts`)

The matcher enforces execution thresholds using `process.hrtime.bigint()` to prevent floating-point microsecond drift. Any pure state step that exceeds $2.00\text{ms}$ ($2,000,000\text{ ns}$) trips an immediate build failure.

```typescript
// packages/300.engine/test/budget-matcher.setup.ts
import { expect } from 'vitest';

interface CustomMatchers<R = unknown> {
  toExecuteWithinBudget(maxDurationMs: number): R;
}

declare module 'vitest' {
  interface Assertion<T = any> extends CustomMatchers<T> {}
  interface AsymmetricMatchersContaining extends CustomMatchers {}
}

expect.extend({
  toExecuteWithinBudget(callback: () => void, maxDurationMs: number) {
    const budgetNs = BigInt(Math.floor(maxDurationMs * 1_000_000));
    
    // Warm-up execution to prime the V8 JIT and eliminate initial cache anomalies
    callback();

    const start = process.hrtime.bigint();
    callback();
    const end = process.hrtime.bigint();

    const elapsedNs = end - start;
    const elapsedMs = Number(elapsedNs) / 1_000_000;
    const pass = elapsedNs <= budgetNs;

    return {
      pass,
      message: () =>
        pass
          ? `[BUDGET_PASS] Execution took ${elapsedMs.toFixed(4)}ms (Budget: <= ${maxDurationMs.toFixed(4)}ms)`
          : `[BUDGET_BREACH] Invariant step exceeded execution ceiling! Took ${elapsedMs.toFixed(4)}ms, strictly capped at ${maxDurationMs.toFixed(4)}ms`
    };
  }
});
```
